Why it exists

Monitoring that stays with the battery

BMS Data Platform is not a replacement for the official JK app. It is a quiet, permanent display for an old phone and a detailed monitor for a computer.

Phone gateway

Select the correct BMS from the Bluetooth list. The phone receives data and serves it over local Wi‑Fi.

Large screen

Open the dashboard on a computer, tablet or TV: charge, current, power, temperatures and cell status.

History and diagnostics

Keep up to a year of local history, compare charts, find imbalance, review SOC events and export data to Excel.

Events and alarms

Connection loss, overheating, over-voltage, balancing and recovery appear as clear, timestamped messages.

Measured charge

See how many amp-hours actually entered the battery from the start of charging to its stop.

BMS thresholds

Charts show cell protection limits, including OVP and high-voltage recovery, with independent colours and controls.

How it works

Four steps to your own display

01

Install Gateway

Use an old Android phone with Bluetooth. Allow Bluetooth and location if Android requests it.

02

Select the BMS

Scan and select your JK/Jikong BMS. The app is not locked to a single MAC address.

03

Open the web panel

Connect the computer to the same Wi‑Fi network and open the address or QR code from the phone.

Monitor

Data updates locally. Internet and a cloud account are not required.

Getting started

From download to first dashboard

The phone works as a Bluetooth gateway beside the battery, while the computer opens the monitor on the same Wi‑Fi network.

Download Android Download Windows
01 · Download and install

Choose the right build

Use the Android and Windows buttons on this page. Install the BMS Gateway APK on the phone; download and unpack the BMS Data Platform ZIP on the computer. On Android, confirm installation from a source you trust.

Jump to downloads GitHub release history

Open the gateway after installation and go to the connection screen.

02 · Connect the battery

Phone → JK/Jikong BMS

Turn on Bluetooth and, if Android asks for it, location access. Allow nearby-device access. Start a scan, wait for it to finish, select your BMS by name or address and connect.

Confirm that SOC, voltage, current, temperature and cells are visible. Then enable the local Wi‑Fi gateway: the phone shows a QR code and an address such as http://192.168.x.x:8765.

03 · Connect the computer

Open the local monitor

Connect the computer and phone to the same Wi‑Fi network. Launch BMS Data Platform, open Connection, enter the address shown on the phone and press Connect. A green gateway status means that data is arriving.

You can now open Overview, Cells, History and Events. Internet is not required; the data stays on your local network.

If it does not connectMove closer to the BMS, run a complete scan again, close the official JK/Jikong app and check that the phone and computer share one network. When the link drops, the monitor marks the data as stale.

Good to know

No hidden promises

Does it write to the BMS?

No. The first version only reads data and never changes protection parameters.

Is internet required?

Only for downloading. Monitoring and the web panel work inside your local network.

Which batteries are supported?

The architecture targets JK/Jikong BMS and configurations from 4 to 32 cells. Check your exact model.

What happens when the link drops?

The monitor marks data as stale, records an event and attempts to reconnect.
